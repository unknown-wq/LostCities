# Топ-10 улучшений для `lostbuildings`

Идеи для следующих фаз развития мода — чтобы кварталы было интереснее находить,
исследовать и лутать. Отсортировано примерно по соотношению «эффект / трудоёмкость».
Пункты 1–3 — это в основном ре-включение уже вырезанного контента (§9 в `PORT-STATUS.md`),
остальные — новый функционал поверх текущего движка.

## 1. Разрушенные здания (damage / rubble)

Сейчас все дома генерируются идеально целыми — «затерянный город» выглядит как новостройка.
Вернуть (упрощённо) систему повреждений оригинала: у части зданий случайно «съедать» сферы
блоков (взрывные кратеры), заменять часть стен на треснувший/замшелый вариант
(`cracked_stone_bricks`, `mossy_*`), ронять обломки вокруг фундамента. Даже простая
вероятностная замена блоков при постройке (5–15 % на этаж, растёт с высотой) резко меняет
атмосферу. Точка врезки — `BuildingEngine.generateBuilding` / `CompiledPalette`.

## 2. Лут и мобы по условиям (Condition-фильтры)

`ConditionRE` уже портирован, но резолвится только по весам — фильтры позиции/части
игнорируются, спавнеры пишутся простым NBT. Включить честный отбор лута по `floor/top/cellar`
и добавить спавнеры/мобов в верхние этажи: чем выше этаж, тем жирнее сундук и опаснее
охрана. Появляется причина лезть на крышу, а не заглянуть в дверь и уйти.

## 3. Подвалы (cellars) с наградой

Движок уже умеет этажи «вниз» (`cellar`-части в данных есть, но `cellars=0`). Включить
1–2 подземных этажа хотя бы у части зданий: тёмные, с лутом и спавнером — классический
риск/награда. `Foundation` уже чистит объём по `maxFloors`, для подвалов достаточно копать
вниз вместо колонны булыжника.

## 4. Уличное освещение и декор улиц

`Streets` кладёт голый `stone_bricks`. Добавить: фонари по обочинам каждые N блоков
(столб + светильник), бордюр из плит, редкие «выбоины» (пропущенные блоки/гравий).
Ночью освещённые улицы среди руин выглядят эффектно и служат навигацией к группе.
Всё делается в `Streets.connect` — точки уже обходятся поколоночно.

## 5. Больше типов зданий и «ролей» в квартале

Сейчас в пул идут `building1..8` равновероятно. Дать зданиям роли: жилой дом, магазин
(бочки/сундуки с «торговым» лутом), библиотека (стеллажи + чарочный лут), сторожевая
башня (высокая, узкая, со спавнером). Минимум — раскладка весов в `LostBuildingConfig`
(`buildings` со взвешенным списком), максимум — портировать ещё паки частей из `1.21/`.

## 6. Вариативность высоты внутри группы

Все здания группы берут этажи из одного диапазона 2–6 равномерно. Сделать «силуэт города»:
одно доминантное высокое здание (до 8–10 этажей) в центре группы, низкие по краям.
Достаточно передавать в `PlaceSettings` пер-здание диапазон в `GroupBuildingPlacement`
в зависимости от индекса/позиции в группе. Квартал станет узнаваемым издалека.

## 7. Редкий «центр города» — большая группа-достопримечательность

Обычные группы — 2–5 зданий. Добавить редкий вариант placed feature (например,
1 к 10 групп): 8–12 зданий, плотная сетка улиц, центральная площадь (фонтан/монумент
из простых блоков) и гарантированный ценный лут. Это цель для экспедиции, а не просто
декорация по пути.

## 8. Интеграция с картами и компасом исследователя

Зарегистрировать структуру/POI так, чтобы город можно было найти через
`/locate`-подобные механики выживания: карта сокровищ у картографа, редкий дроп
«обрывок карты» с указанием на ближайший `lost_city` биом. Сейчас биом ищется только
командой — честного способа найти город в выживании нет.

## 9. Погодно-биомная стилизация (Style по биому)

`StyleSelector` уже существует — использовать его по назначению: в заснеженных регионах
класть снег на крыши и обледеневшие улицы, в пустынных соседях — песчаник-палитру,
в болотных — мох и лианы. Технически это выбор `Style`/палитры от
`level.getBiome(pos)` соседей точки инъекции Biolith. Города перестанут быть
одинаковыми во всех частях мира.

## 10. Датапак-конфигурируемость для игроков

Вынести то, что сейчас захардкожено, в конфиг фичи/датапак: материал улиц
(`Streets.STREET`), ширину, spacing группы (24), шанс редкости (`onAverageOnceEvery(20)`),
целевые биомы Biolith (сейчас PLAINS/FOREST/SAVANNA @0.15). Кодек `LostBuildingConfig`
уже есть — расширить его, и игроки/модпаки смогут тюнить плотность городов без пересборки.

---

Быстрые победы: **4** (фонари — один вечер), **6** (силуэт — пара строк в placement),
**1** (даже примитивный «износ» блоков даёт максимум атмосферы за минимум кода).
Самое «дорогое», но самое ценное для геймплея: **2 + 3** вместе (лут-прогрессия
по вертикали: подвал → этажи → крыша).
